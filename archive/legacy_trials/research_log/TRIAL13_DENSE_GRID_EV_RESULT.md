# Trial 13 result: dense causal grid-EV ranker

## Decision

**Reject Trial 13 and keep internal validation and final OOS locked.**

None of the 54 pre-registered model configurations passed the in-sample
screen. Trial 13 improved cross-sectional ranking, but it did not produce a
robust, cost-resistant grid strategy.

## What changed

Trial 13 replaced Trial 12's rare completed-campaign history with a label for
every eligible ticker-session. Each label was the exact after-cost return from
running the frozen grid from the following open.

Two pooled ridge models were refitted inside every chronological fold:

1. expected net campaign return;
2. expected downside loss.

The daily score was predicted return minus a declared downside penalty. No
ticker identity or future feature entered the model, and the final ten
training sessions were purged so their labels could not cross the deployment
boundary.

## Dense sample

| Measure | Result |
|---|---:|
| Cached valid ticker-session features | 4,131 |
| In-sample deployment observations | 1,575 |
| Training observations per fold | 291–1,515 |
| Model configurations | 54 |
| Configurations with positive score-quintile spread | **54** |

The continuous score contained ranking information: every configuration's top
score quintile had higher average realized campaign return than its bottom
quintile. The observed spread ranged from approximately 0.32% to 0.57%.

## Economic frontier

| Measure | Result |
|---|---:|
| Positive nominal-P&L configurations | 5 / 54 |
| Configurations with PF >= 1.20 | **0** |
| Configurations with positive doubled-cost P&L | **0** |
| Configurations positive after best trade removed | **0** |
| Campaign-count range | 4–25 |
| All-universe control P&L | −VND 256,518 |

The highest nominal-P&L configuration used:

```json
{
  "ridge_penalty": 1000,
  "risk_penalty": 0.0,
  "score_buffer": 0.001,
  "top_k": 3
}
```

Its result was:

| Metric | Result |
|---|---:|
| Campaigns | 9 |
| Entry years represented | 1 |
| Net P&L | **+VND 36,994** |
| Median P&L | +VND 52,187 |
| Profit factor | **1.098** |
| Doubled-cost P&L | **−VND 260,554** |
| P&L after best campaign removed | **−VND 77,011** |
| Incremental P&L versus control | +VND 293,512 |

All nine campaigns occurred in `wf_09`. None sold at an ordinary grid target;
all exited through the trend-shutdown path. The small nominal profit therefore
does not demonstrate repeated profitable grid crossings.

The configuration with the most execution produced 25 campaigns but lost
VND 1,306,669, had a negative median and a 0.354 profit factor. Increasing
activity again exposed the strategy's negative tail economics.

## Pre-registration defect

The in-sample protocol required campaigns in three entry years, but
`wf_01`–`wf_09` deploy only from January 2023 through June 2024. Three
deployment entry years were therefore impossible.

This defect is disclosed rather than repaired after seeing results. It does
not change the decision:

- no configuration reached 30 campaigns;
- no configuration reached profit factor 1.20;
- no configuration survived doubled costs;
- no configuration remained positive after its best trade was removed.

The trial would fail even if the impossible year gate were deleted.

## Interpretation

Dense continuous features fixed Trial 12's estimation-data shortage and
produced a directionally useful ranking across all observations. They did not
solve the economic problem at the executable tail of the score distribution.

The best nominal result was small, concentrated in one fold, sensitive to one
trade and generated by trend exits rather than grid target captures. The
evidence supports the feature-ranking hypothesis weakly, but rejects this
implementation as a profitable grid strategy.
